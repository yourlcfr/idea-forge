# Credits

idea-forge is self-contained: every stage's method is written into this repository. The methods are distilled and adapted from these MIT-licensed projects — the thinking is theirs, the condensed form here is this repo's:

| Stage | Adapted from | Author |
|-------|--------------|--------|
| 1 · Clarify | [superpowers](https://github.com/obra/superpowers) `brainstorming` | Jesse Vincent |
| 2 · Draft prompt | [prompt-master](https://github.com/nidhinjs/prompt-master) | nidhinjs |
| 3 · Grill | [skills](https://github.com/mattpocock/skills) `grilling` | Matt Pocock |
| 4 · Shape check | distilled from [claude-howto](https://github.com/luongnv89/claude-howto)'s lessons (no text copied) | Luong Nguyen |
| 5 · Optimize | [ECC](https://github.com/affaan-m/ECC) `prompt-optimizer` | Affaan Mustafa (skill by YannJY02) |
| 6 · De-AI | [humanizer](https://github.com/blader/humanizer), itself based on Wikipedia's "Signs of AI writing" | blader / WikiProject AI Cleanup |
| 7 · Package | [superpowers](https://github.com/obra/superpowers) `writing-skills` | Jesse Vincent |
| 8 · Handoff | [skills](https://github.com/mattpocock/skills) `handoff` | Matt Pocock |

All listed projects are MIT-licensed. If you want the full, richer originals, install them from their upstream repositories — they cover far more than the slices this pipeline needs.
